**Anycubic NFC Flasher by GDA** — удобное и мощное настольное приложение для управления, редактирования, прошивки и резервного копирования NFC-меток **NTAG213** системы автоматической подачи филамента **Anycubic ACE Pro**.

Приложение разработано для 3D-мейкеров, которые хотят свободно использовать любые сторонние катушки пластика с системой ACE Pro, автоматически передавая принтеру тип филамента, цвет и температурные профили.

## 📋 Описание и возможности

* ⚡ **Мгновенный запуск:** Запуск программы менее чем за 0.5 секунды без браузеров и лишних задержек.
* 🎯 **Все популярные типы пластика:**
  * `PLA`, `PLA+`, `PLA High Speed`, `PLA Matte`, `PLA Silk`
  * `PETG`, `ASA`, `ABS`, `TPU`, `PLA Luminous`
* 🎨 **Удобный выбор цвета:** Встроенная палитра для точного выбора цвета катушки в формате HEX/RGB.
* 💻 **3 Режима оформления интерфейса:**
  * `💻 Авто` — Автоматически подстраивается под системную тему Windows (Темная / Светлая) в реальном времени.
  * `☀️ Светлая` — Принудительная светлая тема.
  * `🌙 Темная` — Принудительная темная тема.
* 📚 **Организованная библиотека дампов:**
  * Автоматическое сохранение снимков тегов в папку `Dumps\<ТипФиламента>\`.
  * Информативные названия файлов со штампом времени, цвета и UID: `PLA_#E10600_04A2B3C4D5E6_20260808_173000.txt`.
* 📂 **Импорт готовых дампов:** Загрузка любых ранее сохранённых профилей в 1 клик для быстрой записи на новые чипы.
* 🟢 **Индикатор подключения `NFC On / Off`:** Мгновенно показывает статус готовности карт-ридера.

## 🚀 Пошаговая инструкция по использованию

1. **Запустите программу** и подключите NFC-ридер к USB. Индикатор в шапке переключится на 🟢 **NFC On**.
2. **Запись новой катушки:**
   * Выберите тип филамента (например, `PLA High Speed`) и желаемый цвет.
   * Нажмите **«💾 Записать тег»** и приложите чистый чип NTAG213 к ридеру.
3. **Считывание параметров:**
   * Нажмите **«📥 Считать тег»** и поднесите метку. Приложение само заполнит все поля.
4. **Дамп и Резервное копирование:**
   * Нажмите **«🔍 Дамп»** для создания полной копии тега.
   * Нажмите **«📁 Папка»**, чтобы открыть папку со всеми сохраненными дампами.
